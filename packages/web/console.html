Connect

Phone or tablet on your home Wi-Fi

Both must be on the same Wi-Fi network.

  1. On this PC, press the Windows key, type cmd and open Command Prompt.
  2. Type ipconfig and press Enter. Find IPv4 Address under your Wi-Fi or Ethernet adapter, for example 192.168.1.23.
  3. On the phone or tablet, open http://<your IPv4 address>:4789 in the browser.

If it will not open, set this PC's network to Private in Windows settings (Network & Internet, Wi-Fi, your network).

Pairing code

Type this code on the device's Systems → Controls page to let it control the aircraft. One code pairs one device.

      vPilot plugin

      ATC voice to text

      Turns what ATC says on your radio into text in the app's Comms tab, with your callsign picked out. It all happens on this PC: no audio or text is sent anywhere. By default it listens only to the ATC apps (vPilot, SayIntentions, BeyondATC and others), so the sim's own sound is left out.

      The sim, music and everything else stay out, even on the same headset. SayIntentions and BeyondATC calls that already arrive as text aren't shown twice. Needs Windows 10 version 2004 or later.

      For VATSIM's fast, clipped radio, large-v3-turbo-q5_0 is the one to use: close to the most accurate model at about a sixth of its work, a 547 MB download. If text lags more than a few seconds behind ATC on your PC, step down to small.en-q5_1 (181 MB), or set CPU use to Fast. Light and Balanced run the engine below normal priority, so it never takes frames from the sim.
